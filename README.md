# Saltline — local copy

Extracted from the public Claude artifact at `https://claude.ai/artifact/BGY1SztrAYcJQHSsnHHGmp`. The game code is bundled inline in `index.html`; the three Google font families are stored locally under `fonts/`. The page has no runtime CDN imports or asset fetches.

Run `./run.sh` and open the local URL it prints. It starts at port 8000 and automatically tries the next available port if needed. Set `PORT=9000 ./run.sh` to choose a different starting port. Press Ctrl+C to stop the server.
